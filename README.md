# ChatGRAP voices

Offline text-to-speech packages used by ChatGRAP Desktop (sherpa-onnx runtime).

| File | What | Source / license |
|---|---|---|
| `sherpa-win-x64.zip` | sherpa-onnx 1.13.8 C API + onnxruntime (Windows x64) | [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), Apache-2.0 |
| `voice-uz-qiz.zip` | Uzbek female voice (VITS, Cyrillic input), exported to ONNX | [MuzaffarSharofitdinov/mms-tts-uzbek-girl-voice_cyrillic](https://huggingface.co/MuzaffarSharofitdinov/mms-tts-uzbek-girl-voice_cyrillic) (CC-BY-4.0), fine-tuned from facebook/mms-tts-uzb-script_cyrillic |
| `voice-ru-irina.zip` | Russian female voice (Piper) | [k2-fsa tts-models](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models), see MODEL_CARD |
| `voice-en-amy.zip` | English female voice (Piper) | [k2-fsa tts-models](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models), see MODEL_CARD |
